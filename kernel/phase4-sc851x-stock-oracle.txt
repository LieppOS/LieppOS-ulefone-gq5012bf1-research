Behavioural oracle
------------------
init_module:
  i2c_register_driver(&sc851x_charger_driver)

cleanup_module:
  i2c_del_driver(&sc851x_charger_driver)

probe(client, id):
  1. dev_err version banner: sc851x_charger_probe (1.0.0_G)
  2. devm_kzalloc 576-byte private structure
  3. devm_regmap_init_i2c with 8/8-bit, max 0x15 configuration
  4. allocate all 50 regmap fields; any failure aborts
  5. i2c_set_clientdata
  6. create DEVICE_ATTR(registers, 0660, show, store); return ignored
  7. read 35 required u32 DT properties; first absent property aborts
  8. read and validate sc,sc851x,irq-gpio
  9. set REG_RST field 0x06[3]=1; log reset failure but continue
 10. sleep 10 ms
 11. issue all 35 field writes in fixed table order; individual errors are logged
     by the field helper but are not propagated
 12. read and dev_err-log every register 0x00..0x15; only the last read status is
     returned by the dump routine
 13. request legacy GPIO as input, convert to IRQ, request falling-edge oneshot
     threaded IRQ named sc851x-irq, call irq_set_irq_wake(irq, 1)
 14. log success and return 0

probe failure path:
  devm_kfree private object; log "sc851x probe fail"; return error. Stock does
  not unwind a previously created sysfs file or explicitly free a requested
  legacy GPIO on later failure.

IRQ thread:
  log "INT OCCURED"; read 0x0c, 0x0d, 0x0e; log FLAG1/2/3 only for successful
  reads; return IRQ_HANDLED. It does not clear faults explicitly, change power
  mode, notify a charger framework, or schedule policy work.

registers sysfs:
  show emits "sc851x:" and successful reads as "Reg[XX] = 0xYY" for 0x00..0x15.
  store accepts two hexadecimal numbers and writes only when two conversions
  succeed and register <= 0x15. This is dangerous debug functionality and was
  not exercised during this read-only investigation.

remove:
  devm_kfree private object. No device_remove_file call in stock.

shutdown:
  write AUDIO_EN field 0x06[2] = 0; print
  "sc851x_charger_shutdown: close AUDIO_EN". Return status is ignored.

suspend:
  dev_info "Suspend successfully!"; when wakeup-capable set IRQ wake to 1;
  disable_irq; return 0.

resume:
  dev_info "Resume successfully!"; when wakeup-capable set IRQ wake to 0;
  enable_irq; return 0.
