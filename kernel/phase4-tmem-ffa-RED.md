MediaTek vendor source, unmodified; only build plumbing (an out-of-tree

## 3. Deltas applied after RED, each stock-proven

### Delta 1 — config visibility (`CONFIG_MTK_PROT_MEM_SSHEAP_V2=1`)

*Evidence:* `trusted_mem_api_alloc` and `trusted_mem_api_unref` are the only two
exports whose CRCs disagreed in RED, and they are the only two whose prototypes
reference `struct ssheap_buf_info` — whose tail (`pmm_msg_list`, `pmm_page`) is
guarded by `CONFIG_MTK_PROT_MEM_SSHEAP_V2`.
*Effect:* exports 15/15 CRC-exact, naturally regenerated by genksyms.

### Delta 2 — config visibility (`CONFIG_MTK_MTEE_MULTI_CHUNK_SUPPORT` off)

*Evidence:* stock defines no `secmem_set_mchunks_region` symbol; its only
consumers (`MTEE_HAPP*`, `MTEE_SDSP*` device entries) are likewise absent.
*Effect:* function set 141/141 exactly.

### Delta 3 — TEE client header family (build plumbing, not driver source)

*Evidence:* stock `tee_session_open` allocates `0x140` bytes and addresses
`context@0x00`, `session@0x108`, `wsm@0x110`, `wsm_buffer@0x138`. Only the
TrustKernel `tee_client_api.h` type graph (`TEEC_Context` 0x108,
`TEEC_Session` 8, `TEEC_SharedMemory` 0x28) yields that layout; the teei/510
header used by the Nothing revision gives an 8-byte `TEEC_Context`.
*Effect:* `secmem_execute` size-exact; `tee_session_open` delta shrank to 4 B.
*Source:* `lieppos/tkcore-recon/include/tk_tee_client_api.h` (already part of
this project's tkcore ABI work) plus a declarations-only prototype block.

### Delta 4 — `TEEC_InitializeContext(NULL, …)` (single-line source delta)

*Evidence:* stock `tee_session_open` emits `mov x0, xzr` immediately before the
`TEEC_InitializeContext` relocation and its `.rodata.str1.1` contains no
`"08030000000000000000000000000000"` entry; the Nothing revision passes
`SECMEM_TL_GP_UUID_STRING`. The TA UUID itself
(`SECMEM_TL_GP_UUID`, passed to `TEEC_OpenSession`) is unchanged.
*Effect:* `tee_session_open` byte-identical; string table 292 = 292.

### Delta 5 — `__LINE__` provenance padding (comments only)

*Evidence:* `pr_*()` call sites embed `__LINE__` as `mov w2, #N`. Stock minus
rebuilt gave a uniform per-file offset: `proc.c +1`, `tee_devices.c +1`,
`mtee_devices.c +3`, `tee_impl/tee_ops.c +5`, everything else 0.
*Effect:* the last 7 functions became byte-identical. The **content** of the
stock lines is unknown and is explicitly not invented; the padding is comment
text whose only purpose is restoring line numbering.

### Delta 6 — `-faddrsig` (build plumbing)

*Evidence:* stock carries a `.llvm_addrsig` section. *Effect:* section set 50 = 50.
