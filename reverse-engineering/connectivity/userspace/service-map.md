Interfaces only. The proprietary libraries were not decompiled. ELF `NEEDED` and device-node
strings for every binary are in [`dependency-map.tsv`](dependency-map.tsv), generated by
`scripts/gen_userspace_deps.py`.

## Legacy / unused on this board

* `wmt_loader`, `wmt_launcher` (`/dev/wmtdetect`, `/dev/stpwmt`, `ttyMT*`, `WMT.cfg`), `autobt`
  and `stp_dump3` belong to the CONNAC1 WMT/STP stack. No init service starts them, and the
  matching kernel modules (`wmt_drv`, `wmt_chrdev_wifi` connac1, `btif`) are not shipped.
* `soc7_0_ram_*` BT/MCU bins in `/vendor/firmware`: BIN2IMG=1 means LK-loaded images are used
  instead (`../bluetooth/firmware-boundary.md`).
* `mt6627/6630/6631/6632/soc_fm_*` FM patches: other FM chips.

## Module load order (vendor_dlkm `modules.load`)

`cfg80211`(1) → `mac80211`(2) → … `mtk-btcvsd`(53) → `mddp`(62) → `wifi_cooling`(73) →
`connadp`(118) → `connscp`(119) → `connfem`(120) → `conninfra`(121) →
`wmt_chrdev_wifi_connac2`(122) → `wlan_drv_gen4m_6878`(123) → `fmradio_drv_connac2x`(129) →
`gps_drv_dl_v051`(130) → `bt_drv_6878`(168) → `bluetooth`(169). system_dlkm loads GKI
`bluetooth`(40) and `rfkill`(47). `gps_pwr`/`gps_scp` are insmod'ed by init after
`vendor.connsys.driver.ready=yes`, and `bt_drv` is also insmod'ed again by `init.bt_drv.rc`.
