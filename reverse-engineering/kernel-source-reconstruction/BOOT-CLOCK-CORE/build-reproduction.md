## Independent clean-checkout run (evidence: `evidence/build/`)

1. Committed the source repository (`e99d919`).
2. `git clone` into `/home/armol/kernel-work/bootclk-cleancheck/repo`; the development
   workspace `bootclk-reconstruction/` (scratch tree, dev ws, patchgen) was **moved away** for
   the whole run.
3. `bootstrap.sh` from the offline pin mirror into a new empty workspace; every tree id verified.
4. `assemble.sh` re-created `src/kdm` and `src/prov` from the pinned archive, applied the three
   patches and verified tree ids `471af75e…` / `4ffb2f3b…`.
5. `make-kout.sh` regenerated the vendor kout and verified the `.config` hash.
6. `derive-provider-crcs.sh`: 2/2 AEE CRCs regenerated from source equal the stock consumer CRCs.
7. B1 built; then every target, kout and provider tree deleted and B2 rebuilt.
8. `b1b2.sh` compared B1/B2: `SHA256SUMS` (6 raw + 6 stripped `.ko` + symvers),
   `INTERMEDIATE-SHA256SUMS` (all 23 target `.o` incl. `.mod.o`), `SOURCE-TREE`,
   `provider-crc-witnesses.tsv`, `config.sha256` — all identical.
9. `verify.py` full stock acceptance on B1: 6/6 PASS (ledgers in `evidence/acceptance/`).

Wall time: bootstrap ~35 s from mirror, B1+B2 ~70 s.
