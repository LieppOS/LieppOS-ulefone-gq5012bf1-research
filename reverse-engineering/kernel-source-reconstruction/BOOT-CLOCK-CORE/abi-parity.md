## Provider verification

* **GKI core**: all 156 core imports (112+14+5+5+5+15) have the exact CRC in GKI 12901745 `vmlinux.symvers`
  (sha256 pinned); 0 mismatches.
* **clk-common → consumers**: resolved in the same modpost run from source; CRCs equal stock
  (exported data objects such as `mtk_mux_clr_set_upd_ops`, `mtk_hwv_mux_ops`,
  `mtk_clk_gate_ops_setclr(_inv)` included). All exports are `EXPORT_SYMBOL_GPL`.
* **AEE** (`aee_is_printk_too_much` 0x29c37d82, `aee_kernel_warning_api_func` 0xdb976d85,
  `EXPORT_SYMBOL`, provider `aee_aed`): regenerated by genksyms from alps5e41 AEE source
  (`evidence/build/provider-crc-witnesses.tsv`), checked against
  `evidence/build/external-provider.symvers`. AEE is not reconstructed or certified by this work.
* **KCFI**: the 9 `__kcfi_typeid_*` absolute symbols match; every function's preamble type
  hash is inside the byte-identical function bodies.
* **Module load dependency**: `.modinfo depends=` is empty for clk-common and `clk-common` for
  the other five (identical to stock); `modules.dep` adds `aee_aed` transitively.
