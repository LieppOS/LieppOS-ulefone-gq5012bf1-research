# Complete kernel ABI and provider boundaries

All164 imported CRC slots,30 exported CRCs/licence buckets,12 absolute KCFI symbols,
raw relocations/symbols and function prefixes match stock. Full ELF equality also covers
indirect operation structures, call targets, strings, dependencies and vermagic.
Common exports30 GPL symbols; platform/EMI export zero. srcversion is absent as in stock;
no field is invented/normalized. Full module metadata is identical.

## Natural external ABI regeneration

12 complete provider objects produce33 required CRC/licence witnesses:
DVFSRC4; vcp_status9; mrdump1; DRAMC2; emi1; mtk-icc-core7; TinySys IPI1;
MMDVFS-debug1; MMDVFS-v3 1; SMI3; SMI-debug1; MMDVFS2.
The #SYMVER records are generated by pinned genksyms from actual definitions and
headers. They must be unique and equal stock consumer CRCs. Their actual export sections
must agree with stock EXPORT_SYMBOL versus EXPORT_SYMBOL_GPL. Producer path basename
must use shipped filename spelling; underscore-normalized modinfo.name is different.

PROVIDER-ABI-WITNESSES.tsv preserves every signature, CRC, licence, defining compile
record and callee KCFI word (or tracepoint data layout). Real provider objects are built
from source separately on every B1/B2 run; their twelve hashes are deterministic.
For function imports, source callee prefix immediately before entry matches the actual
stock provider; tracepoint data is not falsely assigned a function type ID. Those exports
usually lack public __kcfi_typeid_* absolute symbols, so absence is not a failed CFI test.
ABI matching is not whole-provider behavioral certification; existing provider D/G
classifications remain untouched. VCP status has its previously accepted owner/source.

## Actual target consumers

CROSS-COMPONENT-ABI.tsv covers all seven reverse imports:
- mediatek-drm: get_avail_hrt_bw, get_cam_hrt, is_dualpipe_enable,
  register_bw_throttle_notifier (four common exports).
- mtk-cam-isp7sp: mtk_mmqos_wait_throttle_done (one).
- mmqos-mt6878: mtk_mmqos_v2_probe and mtk_mmqos_remove (two).

Stock consumer __versions CRCs equal the rebuilt GPL exports. Full target functions,
source/stock callee words, actual consumer relocations and any caller absolute type IDs
are checked. Platform's two function-pointer type IDs both match their callee signatures.
Direct calls need no invented KCFI check instruction; records distinguish direct call
relocations from indirect operation pointers. Function sizes alone are never acceptance.

Completed camera/MDP/VCodec users also contribute16 real transport imports via separate
mtk-icc-core:8 /4 /4 respectively. Actual complete public core.o generates their CRCs;
source/stock function prefixes agree. These are a separate provider boundary, not newly
invented direct exports from mmqos-common. GPU/APUSYS/GPU-AI-AUX have zero direct target
imports in the authoritative graph; VCP/TinySys are dependencies in the other direction.
