## Providers

* **GKI core:** all 598 imports carry the exact CRC in GKI 12901745 `vmlinux.symvers`
  (347 `EXPORT_SYMBOL`, 251 `EXPORT_SYMBOL_GPL`).
* **Intra-group:** 28 imports resolved in the same modpost run from source; all equal stock.
  `rpmb-mtk`'s `ufs_mtk_rpmb_get_raw_dev` (CRC `0x4dfeeb1d`) resolves to the build-only
  `ufs-mediatek-mod-ise`, reproducing stock `depends=ufs-mediatek-mod-ise,rpmb`.
* **External (uncertified, class D, owners unchanged)**, CRCs regenerated by genksyms from
  ALPS 5e41 (`evidence/build/B1-provider-crc-witnesses.tsv`) and equal to stock:

## Other axes

* **KCFI:** 23 `__kcfi_typeid_*` absolute symbols match; each function's preamble type hash is
  inside the byte-identical function bodies.
* **Operation tables** — `ufs_hba_mtk_vops`, `ufs_mtk_pm_ops`, `ufs_mtk_rpmb_dev_ops`,
  `btag_ufs_vops`, `ufs_mtk_phy_ops`, `ufs_mtk_phy_pm_ops`, `mt_msdc_ops`, `msdc_cmdq_ops`,
  `msdc_dev_pm_ops`, `cqhci_cqe_ops`, `cqhci_crypto_ops`, `mmc_mtk_btag_vops`, `rpmb_fops_ufs`
  (`/dev/rpmb0`), `rpmb_fops_emmc`, the `/proc` `*_fops`/`seq_*_ops`: data objects in
  `DATA-PARITY.tsv`, byte-identical with identical relocations.
* **Sections and symbol order:** every section header field and content identical except the
  build-ID note; `.symtab`/`.strtab` included, so symbol order and strings are identical.
* **Signatures:** none in stock, none in the rebuild.
