equal byte inside the build-ID hash. `.modinfo` (licence, description, author, aliases,
`parm`, `depends`, vermagic, `name`) is identical; none of the ten has `srcversion`; none carries
an appended module signature, and neither do the rebuilds.

Ledgers: `module-parity.tsv`, `FUNCTION-PARITY.tsv`, `DATA-PARITY.tsv`,
`evidence/acceptance/{abi,sections}-parity.tsv`, `relocations-parity.tsv.xz`,
`acceptance.json`. Functions/data are keyed by section, offset, name and size (so the two
same-named static `readl`/`writel` copies in `ufs-mediatek-mod` and `readl_relaxed`/
`writel_relaxed` in `cqhci` are counted separately) and compared on raw bytes. Relocations are
compared raw and semantically (offset, type, target symbol, addend). Every section header field
matches and every section content is identical except `.note.gnu.build-id`. The verifier asserts
that all differing file bytes lie inside the 20-byte build-ID descriptor; only that descriptor
is normalized.

## What was recovered and what was replaced

The 2026-10-04 reconstruction (`reverse-engineering/storage/`) was genuinely exact: its
preserved stripped outputs in the historical tree still equal stock after build-ID
normalization (re-checked). Its *recipe* was not reproducible (details:
`HISTORICAL-BUILD-RECOVERY.md`):

| historical input | problem | replacement |
|---|---|---|
| `lieppos/nfc/kout` | shared, mutable; its `.config` is now GKI-only (`3e489f17…`), not the vendor config used then | `make-kout.sh` from pinned `gki_defconfig` + `mgk_64_k61_defconfig`, `.config` sha256 `8f9d1d29…` (same kout as BOOT-CLOCK-CORE) |
| `stock-all.symvers` | provider CRCs harvested from stock binaries | 5 external CRCs regenerated by genksyms from ALPS source (patch 0004); intra-group CRCs from the same modpost run |
| `cfg/stock-all.ise.symvers` | hand-edited copy re-attributing `ufs_mtk_rpmb_get_raw_dev` to `ufs-mediatek-mod-ise` | the vendor Makefile's own iSE twin is built (build-only); modpost attributes the export to it naturally |
| `cfg/mtk-ack/` | copied header files | regenerated from pinned GKI headers + `patches/ack/`, blob ids verified |
| `cfg/gq5012bf1-no-trustonic.h` + `sb.sh` in-place `Kbuild` rewrites | untracked edits inside the source tree | committed patch 0003 (Kbuild wrappers + `gq5012bf1-board-config.h`) |
| `trees/5e41` patches 0001/0002 | committed only in a scratch tree | preserved verbatim in the repository |

## Boundaries

* Nothing was loaded or executed on hardware. Runtime items: `runtime-tests` in
  `EARLY-BOOT-DEPENDENCIES.md`.
* External providers `aee_aed`, `mrdump`, `irq-dbg`, `pinctrl-mtk-common-v2_debug` (all class D)
  are not certified by this work; only their export CRCs are regenerated from source.
* `ufs-mediatek-mod-ise.ko` is built but not shipped, compared or certified.
* RPMB: normal-world transport only (`RPMB-SECURITY-BOUNDARY.md`). No RPMB data, key or counter
  was read, and no secure-world component was touched.
