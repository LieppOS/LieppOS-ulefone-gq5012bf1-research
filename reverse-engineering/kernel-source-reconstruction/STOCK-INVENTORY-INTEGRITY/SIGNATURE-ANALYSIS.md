# Appended module signature analysis (system_dlkm, 60 modules)

Measured on the authenticated image members and not assumed. Per-module values are in `EXPECTED-VS-OBSERVED.tsv`.

## Stock format

```text
[ ELF image: headers, sections, section header table ]   <- ELF content ends here (= observed size)
[ PKCS#7 SignedData, DER, 681 bytes ]
[ struct module_signature, 12 bytes ]  algo=0 hash=0 id_type=2 (PKEY_ID_PKCS7) signer_len=0 key_id_len=0 pad[3]=0 sig_len=681 (big-endian)
[ "~Module signature appended~\n", 28 bytes ]
```

| Property | Result (all 60) |
|---|---|
| Trailer length | **721 bytes** (681 + 12 + 28) for every module. Measured, not assumed |
| `id_type` | 2 = PKCS#7 |
| PKCS#7 | DER `0x30`; digest SHA-256; RSA; issuer `CN=Build time autogenerated kernel key`; serial `0x06700AC83CF56F282ABB69E134656E22CFC14A74` (one signer for all 60) |
| Distinct PKCS#7 blobs | 60 (per-module signatures) |
| ELF content end | equals `stock_size − 721` for every module (computed from section and section-header extents) |
| vendor_dlkm / vendor_boot modules | 0 of 411 occurrences carry a trailer (unsigned) |

## Damaged copies

| Property | Result (all 60) |
|---|---|
| Size delta (expected − observed) | exactly 721 |
| Observed bytes == image member `[: size − 721]` | yes (`observed_equals_image_unsigned_prefix`) |
| Trailer magic present | no |
| SHA-256 of unsigned prefix | recorded per module (`unsigned_prefix_sha256`) |
| Code, data, symbols, relocations, `.modinfo`, `.BTF` | unchanged. The bytes before the trailer are identical, so only the signature is missing |

The damage is therefore a pure signature strip with no other byte change. That distinguishes it from a rebuilt,
re-signed or otherwise substituted module, all of which the restoration tool refuses.

## Why only system_dlkm

GKI `system_dlkm` modules are signed by the GKI build (`ab-ab12901745` vermagic). Vendor modules are unsigned. A
section-preserving `llvm-objcopy` rewrite is byte-identical for an unsigned module but drops the unsectioned trailer
of a signed module. Of the 71 files rewritten, only the 60 signed ones changed.
